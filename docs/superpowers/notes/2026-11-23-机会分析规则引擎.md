## 本次交付

借鉴 bids-spider 的个人业务机会分析能力（`analyze_opportunities.py` 规则引擎），落地团队工作台搜索页。本迭代只做**规则引擎**，AI 精读标书留待下一迭代。

### 1. 规则引擎模块（新增 `collectors/opportunity.py`）

- `match_keywords(title, core, secondary, exclude)`：排除词优先 → 剔除；标题命中核心词 → `direct`；命中次要词 → `related`。
- `body_core_leads(content, core, exclude)`：标题无信号时，正文前 4000 字命中 ≥3 个不同核心词且排除词 <2 次 → `leads`（意向线索，防噪声）。
- `urgency(deadline, today)`：无 deadline → `unknown`；≤0 → `expired`（⛔）；≤7 → `urgent`（🔴）；≤14 → `prep`（🟡）；其余 → `relaxed`（🟢）。
- `classify(...)`：组合标题/正文相关度与截止紧迫度，输出 `relevance`/`urgency_level`/`days_left`。
- `DEFAULT_KEYWORDS`：复用 bids-spider 服务器/IT/AI 三档词表（core/secondary/exclude）。

### 2. 存储层接入（`storage/workbench.py`）

- `__init__` 首次运行默认写入 `opportunity_keywords` 配置（`workbench_settings`）。
- `search()` 用完整 content 实时计算相关度/紧迫度，附加到返回行（content 不透出，传输量不变）；新增 `relevance` 参数，按相关度 Python 层过滤（total 在过滤时重算为过滤后条数）。

### 3. API（`api.py`）

- `/api/projects` 新增 `relevance` 查询参数（`direct`/`related`/`leads`）。
- `/api/meta` 返回 `opportunity_keywords` 配置。

### 4. 前端（`web/index.html` + `web/assets/app.js`）

- 搜索筛选区新增"相关度"下拉（全部/直接相关/相关/意向线索）。
- 列表卡片：`card-top` 显示相关度标签（直接相关=绿、相关=默认蓝、意向线索=橙）；`project-meta` 显示紧迫度徽章（🔴🟡🟢 距截止X天 / ⛔已过期 / 未提取截止）。
- 复用既有 `tag()` 组件与 CSS 变量，未自创色值。

## 运维说明

- 关键词配置在 `workbench_settings` 表 `opportunity_keywords`（JSON）。本迭代不做界面编辑，如需调整可改库：`UPDATE workbench_settings SET value='...' WHERE key='opportunity_keywords'`，重启后生效（配置在 `__init__` 时读取）。
- 相关度实时计算，无需落库；正文由上一迭代的 DetailFetcher 后台补抓，正文越全，`leads`（意向线索）判定越准。
