## 本次交付

机会分析规则引擎（上一迭代）的关键词词表从"改库"升级为"设置页可视化编辑，保存即生效"。

### 1. 后端接口（`api.py`）

- 新增 `OpportunityKeywordsInput`（继承 `Input`，`extra="forbid"`）：
  - `core`/`secondary`/`exclude` 三档 `list[str]`，各最多 200 词
  - `clean_words` 校验：strip、去空、去重（保序）、单词 ≤30 字符（超长静默丢弃）
- 新增 `PATCH /api/settings/opportunity-keywords`：
  - 请求体 `{core, secondary, exclude}` 数组
  - 写入 `workbench_settings`（key=`opportunity_keywords`，覆盖式 upsert）
  - 返回 `{"saved": true, "keywords": {...}}`（规范化后的配置）
  - 非法输入返回 400（pydantic ValidationError 经既有 ValueError handler 处理；手动 `model_validate(request.json())` 解析，避免 FastAPI 默认 422 改变既有接口行为）

### 2. 前端（`web/index.html` + `web/assets/app.js`）

- 设置页新增"机会分析关键词"面板（自动更新面板之后）：三档文本框（每词一行）+ 保存按钮 + 说明文案（核心→直接相关、次要→相关、排除→剔除、正文 3+ 核心词→意向线索）
- `loadOpportunityKeywords()`：`refreshMeta()` 时从 `meta.opportunity_keywords` 填充文本框
- `saveKeywords` 事件：三档按 `\n` 拆数组 → PATCH → `refreshMeta()` → 提示"已保存，相关度计算即时生效"

### 3. 生效机制

`search()` 每次实时读取 `setting('opportunity_keywords')` → **保存即生效，无需重启**（天然满足）。

## 测试结果
