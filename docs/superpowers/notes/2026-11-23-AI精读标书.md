## 本次交付

借鉴 bids-spider 的 deerflow LLM 精读能力，落地团队工作台。用户可对单条/批量公告触发 AI 精读，AI 输出结构化研判（采购单位/预算/截止/技术要点/业务关联度/跟进建议/风险提示）+ 建议文本，存库并在详情页展示；支持采集后自动精读直接相关公告。

### 1. AI 精读模块（新增 `collectors/ai_read.py`）

- `DEFAULT_AI_SETTINGS`/`load_ai_config`：配置读 `workbench_settings`（key=`ai_read_settings`）：enabled/deerflow_cli/gateway/timeout/recursion_limit/detail_len/auto_enabled/auto_limit。
- `locate_deerflow_cli`：显式路径 → `shutil.which` → 常见目录探测（~/.local/bin、~/bin、/usr/local/bin、/opt/homebrew/bin）。
- `build_prompt`：标题 + 结构化字段（预算/截止/采购人/中标）+ 正文前 detail_len 字；要求模型输出 JSON 并附建议文本，可 web_fetch 核实。
- `run_deerflow`：subprocess 调 `deerflowcli --output-dir --timeout --no-stream [--gateway] [--recursion-limit] <task>`；错误分类（CLI 缺失/凭据无效/限流/网关不可达）。
- `parse_result`：剥 JSON 围栏 → 取首尾大括号 → json.loads；失败降级 `{error, raw}` 不崩溃。
- `compute_hash`：标题+字段+正文 md5，用于精读缓存（内容变化自动重读）。

### 2. 存储层（`storage/workbench.py`）

- 新增 `ai_reads` 表（project_id PK/status/input_hash/result_json/error/created_at/updated_at）。
- 默认写入 `ai_read_settings`。
- `save_ai_read`（upsert）/`ai_read`（result_json 反序列化）方法。

### 3. 精读服务（`collectors/collection.py` 新增 `AIReadFetcher`）

- 后台线程（独立 stop），`request(key)` 手动队列优先，扫 `ai_reads` pending。
- `ready + input_hash 一致` → 跳过（缓存复用）；失败置 error。
- 60s 限速串行，避免频繁调本地 Gateway。
- `maybe_schedule()`：采集完成后对 relevance=direct 且无当前结果（或 hash 变化）的公告写 pending 并入队，受 auto_limit 限制（`_collect` finally 触发）。

### 4. API（`api.py`）

- `POST /api/projects/{key}/ai-read`：单条触发（入队）。
- `POST /api/ai-read/batch`：批量（body `{keys:[...]}` 或 `{filter:{relevance:...}}`，≤50）。
- `PATCH /api/settings/ai-read`：保存 deerflow 配置。
- `GET /api/projects/{key}`：详情返回 `ai_read`。
- `GET /api/meta`：返回 `ai_read_settings` + `ai_read_job`。

### 5. 前端（`web/index.html` + `web/assets/app.js`）

- 详情页公告信息 tab 新增"AI 精读"按钮：未启用提示、触发入队、8s 轮询、结果展示（info-item 结构化字段 + 建议文本 section）。
- 设置页新增"AI 精读"配置面板：启用开关、自动精读开关、CLI 路径、Gateway、超时、每日上限。

## 运维说明

- 使用前需在设置页启用 AI 精读并配置 deerflow CLI 路径（留空自动探测）与 Gateway 地址（默认 http://127.0.0.1:8001）。未配置时精读按钮提示"请先在设置页启用 AI 精读"。
- 精读后台串行执行（60s/条），单条可能需数分钟，详情页自动轮询。
- 精读结果缓存：内容（标题/字段/正文）不变时不重复调模型。
- 采集完成后若开启"自动精读直接相关公告"，对 relevance=direct 公告自动排队（受每日上限限制）。
