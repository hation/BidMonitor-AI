# 简单提示词 → 功能 触发映射表（BidMonitor-AI）

> 用途：用户常以一句话触发本项目功能（如"采集公告""搜标讯""导入来源"）。本表把**简单提示词路由到对应应用页面 / API / 操作**，是 Agent 判断意图的第一依据。
> 使用规则：
> 1. 命中触发词 → 按"默认行为"执行（具体执行细节以各应用源码与 [README.md](../README.md) 为准）。
> 2. 未命中 → 先向用户确认意图（AskUserQuestion），不得自行猜测。
> 3. **新功能上线时，把触发词补进本表**（提交 body / 交付记录同步注明）。
> 4. "执行后产物"列填写触发后产生的文件/落库结果；无文件产物时注明落库或"无文件"。
> 5. 本项目含三个应用：团队工作台（Web，默认 8765）、桌面版（Tkinter GUI）、历史 Web 后台（默认 8080）。入口列按应用标注。
